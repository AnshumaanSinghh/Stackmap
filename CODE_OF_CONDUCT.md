# Code of Conduct

Stackmap follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, give and take feedback gracefully, and focus on what is best for the people using the project. Harassment, insults and personal attacks are not welcome in issues, pull requests, discussions or any other project space.

Report unacceptable behaviour privately to the maintainer through a [GitHub security advisory](https://github.com/AnshumaanSinghh/Stackmap/security/advisories/new) or by contacting [@AnshumaanSinghh](https://github.com/AnshumaanSinghh). Reports are handled confidentially.
